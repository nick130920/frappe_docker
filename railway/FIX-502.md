# Corregir 502 en Railway

Checklist en el [dashboard](https://railway.com/project/14025ec2-fe3b-422e-a4ae-672bb7b156bc):

## 1. Servicio `frontend`

| Ajuste | Valor |
|--------|--------|
| **Start Command** | `start-frontend.sh` |
| **Networking → Puerto** | `8080` |
| **Volume** | Mismo que `backend` → mount `/home/frappe/frappe-bench/sites` |

Variables (opcional si usas `start-frontend.sh`):

```env
BACKEND=backend:8000
SOCKETIO=websocket:9000
PORT=8080
FRAPPE_SITE_NAME_HEADER=$host
```

## 2. Redeploy

Tras subir la imagen nueva (GitHub Actions):

```powershell
railway login
cd C:\Users\namc1\frappe_docker
railway link -p rrhh-pwd-hrms
railway redeploy -s frontend -y
railway redeploy -s websocket -y
```

## 3. Comprobar logs

```powershell
railway logs -s frontend -n 30
```

Debe verse: `frontend: BACKEND=backend:8000 ... PORT=8080` y nginx arrancando (no Gunicorn).

## 4. Si sigue 502

- `backend` debe estar **Online**.
- `websocket` con Start Command: `node /home/frappe/frappe-bench/apps/frappe/socketio.js`
- Mismo volumen `sites` en frontend que en backend.
